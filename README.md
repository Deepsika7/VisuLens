# 🎨 VisuLens: AI-Powered Visual Search Engine

**VisuLens** is a premium, Pinterest-inspired visual search engine that uses deep learning (**ResNet50**) to find similar images based on their visual features. Built for high performance and aesthetic excellence.

---

### 🌐 Live Links
- **🚀 Frontend:** [https://visulens-frontend-vj4o.onrender.com](https://visulens-frontend-vj4o.onrender.com)
- **🔗 Backend API:** [https://visulens-backend-vj4o.onrender.com](https://visulens-backend-vj4o.onrender.com)

---

### ✨ Features
- **AI-Powered Search**: Uses ResNet50 for high-dimensional feature extraction.
- **Pinterest Aesthetic**: Premium pastel UI with a smooth masonry grid.
- **Real-time Processing**: Fast similarity matching using Cosine Similarity.
- **Micro-animations**: Enhanced UX with Framer Motion.
- **Free-Tier Optimized**: CPU-only PyTorch and indexed embeddings for zero-latency.

---

### 🚀 Getting Started

#### 1. Backend Setup
1. Navigate to the `backend` folder.
2. Create virtual environment: `python -m venv venv`.
3. Activate: `.\venv\Scripts\activate`.
4. Install: `pip install -r requirements.txt`.
5. Run: `python app.py`.

#### 2. Frontend Setup
1. Navigate to the `frontend` folder.
2. Install: `npm install`.
3. Run: `npm run dev`.

---

### 🛠️ Technology Stack
- **Frontend**: React v18, Vite, Framer Motion, Tailwind CSS, Lucide Icons, Axios.
- **Backend**: Flask, PyTorch (CPU-Only), Scikit-learn, Pillow.
- **AI Model**: Pre-trained ResNet50 (2048-dimensional feature extractor).
- **Storage**: Binary Pickle (.pkl) for vector embeddings, JSON for profiles.
